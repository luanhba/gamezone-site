🎮 GameZone
A GameZone é uma loja virtual de jogos desenvolvida com o objetivo de criar uma interface simples, moderna e intuitiva para apresentação de produtos.

🛠️ Tecnologias
HTML5
CSS3
Bootstrap 5.3.8


✨ Funcionalidades
Catálogo de jogos
Página de produtos
Design responsivo
Interface simples e moderna

Recursos do Bootstrap
1: Navbar: menu de navegação do site.
2: Container: organiza e centraliza o conteúdo.
3: Grid: divide o conteúdo em linhas e colunas.
4: Cards: organiza produtos e informações.
5: Buttons: cria os botões do site.
6: Badges: destaca categorias e informações.
7: Alert: mostra avisos e promoções.
8: Forms: organiza o formulário de contato.
